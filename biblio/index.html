Sincronizar con GitHub

Sobre tu clave: crea una clave fine-grained con permiso Contents: Read and write solo para tu repositorio y ponle vencimiento. Se guarda únicamente en este navegador; nunca se sube a GitHub ni se incluye en las exportaciones. El archivo de datos sí queda público (son trozos de código, no información privada).
¿Cómo creo mi clave paso a paso?
  1. Entra a github.com → tu foto (arriba a la derecha) → Settings.
  2. Abajo: Developer settings → Personal access tokens → Fine-grained tokens.
  3. Generate new token. Ponle un nombre (ej. «Biblioteca») y una fecha de vencimiento.
  4. En Repository access: Only select repositories y marca tu repo.
  5. En Permissions → Repository permissions → Contents: ponlo en Read and write.
  6. Generate token y copia la clave (empieza con github_pat_…). Pégala aquí abajo.
